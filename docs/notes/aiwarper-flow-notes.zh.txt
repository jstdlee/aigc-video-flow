# x.flow2.txt — AI 视频工作流摘要（来源：@AIWarper 2025-09-29 X 推文串）
# 主题：用 Claude Opus（agent harness）+ Seedance 2.5 + Suno + DaVinci Resolve 一步到位产出 30 秒电影感动作片（细雨中海战 / 孤独机甲题材）

## 总览
整个 30s 成片 ≈ 一次性生成（essentially one-shot），人工介入极少：
人只做了两件事 —— ①用语音听写口述总提示词、②从约 20 张氛围图里手挑 5 张。
其余（分镜图、视频生成、剪辑、调色、配乐贴合）全部交给 agent 执行。

## 流程
1. 氛围/分镜图（~25 张，UNI 1.1 图像模型）
   - 约 $0.04/张，作者说"便宜到可以随便轰"。
   - 实际生成约 20–25 张 mood images，人工挑出 5 张作为视频条件输入。
2. 视频生成：Seedance 2.5，单次生成（one single generation）
   - 输入 = 5 张挑选的图 + 一段很长的英文生成目标提示词。
   - 提示词开头即 [Generation Goal]：一条连贯、大量切镜的电影感动作序列，
     细雨中的海战场景……（作者口述，语音转文字写成，含明确方向指引）。
   - 原始输出为 720p / 30s。
3. 上采样：人工把 720p 放大到 4K（人工步骤，非 agent）。
4. 配乐：Suno v6（mini 档，免费）生成 30s 音乐轨。
5. 剪辑/后期/调色：把 4K 视频 + 音乐轨交给 Claude Opus 在 DaVinci Resolve 内完成
   - 方式 = computer use（屏幕操控），没有 CLI/MCP/API——"除非它背着我装了工具，
     否则就是 computer use"。
   - 作者预先打开 DaVinci 并预载了 Seedance 视频 + Suno 音轨（自述这步"可能也不一定要手动做"）。
   - Opus 自己完成剪辑、后处理、调色，并把音乐轨剪到与画面对齐（音乐贴合也是 Opus 做的）。
6. 外部模型接入：harness 通过 API 直调图像/视频/放大服务（Magnific 放大、fal.ai 等），
   可让 harness 在循环里自行迭代、收敛到好的提示词——"图像便宜，视频显然烧钱"。

## 成本（作者自报）
- Seedance 720p 30s 单次生成 ≈ $10（最贵的一项）
- 约 25 张图 × ~$0.04 ≈ $1
- Suno v6 mini：免费
- Claude Opus：月度订阅内含（无按次费用）
- 合计 ≈ $15

## 关键要点
- Agent 作为"制作人"而非仅聊天：harness 持有 API 密钥 + computer-use 权限，
  从分镜→生成→放大→剪辑→调色→音乐贴合一条龙。
- 人类职责收缩为：口述创意方向（语音输入即可）、挑选素材（5/20 张）、准备工具环境（开 DaVinci、预载素材）。
- 成本结构：图像生成几乎白送 → 可大量刷图选优；视频生成与上采样是主要开销。
- 首次用 Opus 接管 DaVinci Resolve，作者"100% 推荐"，且整个流程配额消耗"几乎不算什么"。
