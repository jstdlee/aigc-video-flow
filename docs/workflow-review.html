What blocks commercial class

GapWhy a client caresSeverity
No exact-product pathThe model swapped Kaz's car for a different design. On a product, that is a wrong logo or label: the ad is rejected.blocker
Model and asset rights not checkedCommercial use terms for H3, Qwen-Image, Krea 2, agy and grok outputs, and CC-BY assets, are not on file.blocker
Native size is 1280×704Masters need 1080p or 4K, and 16:9, 9:16 and 1:1 versions. Upscale quality is not measured.high

What is next

Verification plan

Use one small paid-style job to test every untested stage: a 15 s product spot with one bottle, five shots, in 16:9 and 9:16. A product shows brand drift at once, and a narrative film does not. Each test has a measurable pass line. Tick a test when it passes; ticks are saved in your browser only.

Order of work

Start here

Today, with no GPU: V1, the rights audit. If a model fails it, everything built on that model has to change, so it goes first.

When memory is free: model the bottle in Blender, then run V2 and V3 on the same shot. Together they tell you which shots of an ad must be composites.

Then: V4 (take 2), V5 and V6. Run V7 to V9 on the finished 15 s spot.

GPU runs keep the existing rule: estimate memory first, stay under 80 % (about 97 GiB), one GPU job at a time, no CPU render in parallel.
